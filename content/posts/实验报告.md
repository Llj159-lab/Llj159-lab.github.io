## 一、实验概述

  本次实验包含两个相互独立的深度学习任务。实验6在 CIFAR-10 数据集上实现残差网络，完成 BasicBlock、Bottleneck、ResNet18 和 ResNet50 的构建、训练或前向验证；实验7在 Indian Pines 高光谱数据集上实现 HybridSN，完成数据预处理、3D 卷积与 2D 卷积特征提取、训练、分类评估及结果可视化。




## 二、实验6：CIFAR-10 上的 ResNet 图像分类

### 1. 实验目的

1. 理解残差学习和捷径连接的基本思想。
2. 掌握 BasicBlock 和 Bottleneck 两种残差单元的实现方法。
3. 使用 PyTorch 搭建适用于 CIFAR-10 的 ResNet18，并完成训练和测试。
4. 构建 ResNet50，验证 Bottleneck 网络的前向传播和输出维度。
5. 理解数据增强、批归一化、交叉熵损失和 Adam 优化器在图像分类中的作用。

### 2. 实验原理

  普通卷积网络需要逐层学习完整映射，网络加深后容易出现优化困难。残差网络通过捷径分支将输入直接传递到输出，使残差块学习：

<div align="center"><strong>y = F(x, W) + x</strong></div>

  当输入和输出的通道数或空间尺寸不一致时，捷径分支使用带步幅的 1×1 卷积进行投影。BasicBlock 使用两个 3×3 卷积；Bottleneck 使用 1×1、3×3、1×1 三个卷积，其中首尾卷积负责调整通道数，中间卷积负责提取空间特征。

### 3. 实验环境与数据

  实验在 Google Colab 中完成，主要使用 Python、PyTorch、Torchvision、NumPy 和 Matplotlib。程序通过 `torch.cuda.is_available()` 自动选择 CUDA 或 CPU。

  CIFAR-10 包含 10 个类别。训练集采用随机裁剪、随机水平翻转、张量转换和标准化；测试集只进行张量转换和标准化。数据加载器的批大小设置为 128，训练集打乱样本顺序，测试集保持原顺序。

### 4. 实验步骤

#### 4.1 导入库与定义 BasicBlock

  首先导入 PyTorch、Torchvision、NumPy 和绘图库，然后定义 BasicBlock。主分支包含两个卷积层、两个批归一化层和 ReLU 激活函数；捷径分支在尺寸或通道数发生变化时使用 1×1 卷积。

![BasicBlock 代码](/posts/实验截图/6.1.png)

<div align="center">图6-1 BasicBlock 残差块的导入环境、网络定义和前向传播代码</div>

  BasicBlock 的核心前向传播如下：

```python
def forward(self, x):
    out = F.relu(self.bn1(self.conv1(x)))
    out = self.bn2(self.conv2(out))
    out = out + self.shortcut(x)
    return F.relu(out)
```

#### 4.2 定义 Bottleneck

  Bottleneck 的扩张系数设置为 4。输入先经过 1×1 卷积调整通道数，再经过 3×3 卷积提取特征，最后通过 1×1 卷积将通道数扩展为原来的 4 倍。主分支与捷径分支相加后进行 ReLU 激活。

![Bottleneck 代码](/posts/实验截图/6.2.png)

<div align="center">图6-2 Bottleneck 残差单元的卷积结构、捷径分支和前向传播代码</div>

#### 4.3 CIFAR-10 数据预处理

  训练集图像先进行随机裁剪和随机水平翻转，再转换为张量并按 CIFAR-10 的通道均值和标准差进行标准化。测试集不进行随机增强。训练集和测试集分别通过 DataLoader 以批大小 128 读取。

![CIFAR-10 数据预处理代码](/posts/实验截图/6.3.png)

<div align="center">图6-3 CIFAR-10 数据增强、标准化、数据集读取和 DataLoader 配置</div>

#### 4.4 搭建 ResNet18

  ResNet18 的初始卷积输出 64 个通道，后续四个残差阶段的通道数分别为 64、128、256 和 512，每个阶段包含两个 BasicBlock。阶段之间使用步幅 2 完成下采样，最后使用 4×4 平均池化和全连接层输出 10 个类别的得分。

![ResNet18 网络定义](/posts/实验截图/6.4.png)

<div align="center">图6-4 ResNet18 的网络层次、残差阶段和前向传播过程</div>

#### 4.5 设置损失函数和优化器

  分类损失使用交叉熵损失函数，参数优化使用 Adam，学习率设为 0.001。

![损失函数与优化器](/posts/实验截图/6.5.png)

<div align="center">图6-5 ResNet18 的交叉熵损失函数和 Adam 优化器设置</div>

  训练迭代的核心代码如下：

```python
optimizer.zero_grad()
outputs = net(inputs)
loss = criterion(outputs, labels)
loss.backward()
optimizer.step()
```

#### 4.6 训练 ResNet18

  模型训练 10 个 epoch。每次迭代先将图像和标签移动到运行设备，然后进行前向传播，计算损失并完成反向传播和参数更新。程序每 100 个小批次输出一次当前损失。

![ResNet18 训练过程](/posts/实验截图/6.6.png)

<div align="center">图6-6 ResNet18 训练 10 个 epoch 的损失输出</div>

  从训练日志可以看出，损失从第 1 个 epoch 的较高水平逐步下降到第 10 个 epoch 的较低水平，说明模型已经学习到 CIFAR-10 的图像特征。

#### 4.7 测试模型

  训练结束后将网络切换为评估模式，并在 `torch.no_grad()` 环境中遍历测试集。通过输出得分最大的类别作为预测结果，统计预测正确的样本数量。

![ResNet18 测试代码与准确率](/posts/实验截图/6.7.png)

<div align="center">图6-7 ResNet18 测试过程和 CIFAR-10 测试准确率输出</div>

  测试集共有 10000 张图像，最终准确率为 **84.75%**。

#### 4.8 验证 ResNet50 输出维度

  根据 ResNet50 的 Bottleneck 结构构建网络，随机生成形状为 (4,3,32,32) 的输入张量，检查模型输出形状。

![ResNet50 输出形状验证](/posts/实验截图/6.png)

<div align="center">图6-8 ResNet50 随机输入和输出形状验证，输出为 `torch.Size([4, 10])`</div>

  该结果说明网络能够接收批大小为 4、3 通道、32×32 的 CIFAR-10 图像，并为每个样本输出 10 个类别得分。

### 5. 实验结果与分析

#### 5.1 ResNet18 分类结果

  ResNet18 经过 10 个 epoch 训练后，训练损失总体下降，测试集准确率达到 **84.75%**。该结果说明残差连接能够支持较深的卷积网络稳定训练，并能在 CIFAR-10 上提取有效的图像分类特征。

  准确率仍然受到训练轮数、学习率、数据增强方式、网络初始化和随机批次顺序等因素影响。当前实验主要验证网络构建和训练流程，没有继续进行学习率调度或更长时间训练，因此结果还有提升空间。

#### 5.2 ResNet50 结构验证结果

  ResNet50 的输出形状为 `torch.Size([4, 10])`，与输入批大小和 CIFAR-10 类别数一致。该实验验证了 Bottleneck 结构、下采样操作和最终分类层之间的维度衔接正确。由于本次运行只进行了随机输入的前向测试，不能将该结果理解为 ResNet50 的测试准确率。

### 6. 实验小结

  实验6完成了 BasicBlock、Bottleneck、ResNet18 和 ResNet50 的实现。通过 CIFAR-10 训练，掌握了从数据预处理、模型构建、损失计算、反向传播到测试评估的完整流程；通过随机输入验证，确认了 ResNet50 的张量维度设计正确。



## 三、实验7：Indian Pines 高光谱图像分类

### 1. 实验目的

1. 掌握高光谱图像数据的读取、PCA 降维和空间窗口构造方法。
2. 理解 3D 卷积和 2D 卷积在高光谱图像分类中的作用。
3. 实现 HybridSN 的 3D-CNN 与 2D-CNN 层级结构。
4. 完成 Indian Pines 数据集的训练、测试、分类报告和混淆矩阵分析。
5. 将模型预测结果恢复为整幅分类图，并与地面真值图进行比较。

### 2. 实验原理

  高光谱图像可以表示为 H×W×B 的三维数据立方体，前两个维度表示空间位置，第三个维度表示光谱波段。与普通 RGB 图像相比，高光谱数据的波段数量多，包含丰富的材料光谱信息。

  3D 卷积同时沿光谱方向和空间方向滑动，可以学习局部光谱—空间联合特征；2D 卷积主要在空间平面上提取纹理和形状特征。HybridSN 先使用多层 3D 卷积提取联合特征，再将特征变换为 2D 卷积可以处理的形式，最后使用全连接层完成分类。

### 3. 实验环境与数据

  实验使用 Indian Pines 数据集：

- 高光谱影像文件：`Indian_pines_corrected.mat`；
- 地面真值文件：`Indian_pines_gt.mat`；
- 影像尺寸：145×145×200；
- 标签矩阵尺寸：145×145；
- 类别数量：16 类；
- PCA 保留主成分数：30；
- 空间窗口大小：25×25；
- 测试集比例：90%；
- 训练样本数：1024；
- 测试样本数：9225。

### 4. 实验步骤

#### 4.1 定义 HybridSN 网络

  HybridSN 包含三层 3D 卷积和一层 2D 卷积。三层 3D 卷积的通道数依次为 1→8、8→16、16→32，卷积核依次为 (7,3,3)、(5,3,3) 和 (3,3,3)。之后将 3D 特征整理为 2D 特征图，使用 64 个 3×3 卷积核继续提取空间信息。全连接层依次为 256、128 和 16 个神经元，Dropout 比例为 0.4。

![HybridSN 网络定义](/posts/实验截图/7.3.png)

<div align="center">图7-3 HybridSN 的 3D 卷积、2D 卷积、全连接层和前向传播代码</div>

  模型的核心结构如下：

```python
self.conv3d_1 = nn.Conv3d(1, 8, kernel_size=(7, 3, 3))
self.conv3d_2 = nn.Conv3d(8, 16, kernel_size=(5, 3, 3))
self.conv3d_3 = nn.Conv3d(16, 32, kernel_size=(3, 3, 3))
self.conv2d = nn.Conv2d(32 * 18, 64, kernel_size=(3, 3))
self.fc1 = nn.Linear(64 * 17 * 17, 256)
self.fc2 = nn.Linear(256, 128)
self.fc3 = nn.Linear(128, 16)
```

#### 4.2 定义 PCA、补零、切片和数据集划分函数

  首先将每个像素的光谱向量展平为二维矩阵，使用 PCA 保留 30 个主成分，再恢复为空间影像。随后对边缘进行补零，以便所有像素都能提取大小一致的 25×25 窗口；标签为 0 的背景像素被过滤。最后使用分层抽样划分训练集和测试集。

## 四、实验要求中的思考题

### 1. 训练 HybridSN 后多次测试，为什么每次分类结果可能不同？

  模型参数通常由随机值初始化，训练数据的批次顺序也会随机变化；如果训练集和测试集采用随机划分，划分结果同样会影响最终指标。GPU 上部分算子还可能存在非确定性。上述因素会使每次训练得到的参数不同，因而预测结果和 OA、AA、Kappa 也会发生变化。

  为了进行公平比较，应固定 Python、NumPy 和 PyTorch 的随机种子，固定数据划分，并在条件允许时启用确定性算法。更稳妥的做法是使用多个随机种子重复实验，报告均值和标准差，而不是只报告一次结果。

### 2. 如何进一步提升高光谱图像分类性能？

  可以从数据、模型和训练策略三个方面改进：

1. 选择合适的 PCA 主成分数和空间窗口大小，避免降维过度或窗口过大。
2. 使用数据增强、类别加权损失或重采样，缓解类别数量不平衡。
3. 添加学习率调度、早停和最佳模型保存，降低过拟合风险。
4. 引入光谱注意力、空间注意力、多尺度卷积或 Transformer 等结构，增强对光谱和空间关系的建模能力。
5. 采用验证集选择超参数，并通过多次重复实验检验改进是否稳定。

### 3. depth-wise convolution 和分组卷积有什么区别与联系？

  分组卷积将输入和输出通道划分为若干组，每组独立进行卷积，组数可以从 1 到输入通道数。depth-wise convolution 是分组卷积的特殊情况：每个输入通道单独对应一组，组数等于输入通道数，每组通常只产生一个输出通道。

  因此，depth-wise convolution 的参数量和计算量都很小，但不同通道之间不会直接发生信息混合，通常需要再接一个 1×1 point-wise convolution 完成通道融合。普通分组卷积可以在每组内使用多个输出通道，表达能力通常强于单独的 depth-wise convolution。

### 4. SENet 的注意力可以加在空间位置上吗？

  可以。SENet 原始的 SE 模块主要对通道进行建模，通过全局平均池化获得通道描述，再生成每个通道的权重。如果希望关注空间位置，可以在通道注意力之外增加空间注意力模块，例如 CBAM 的空间注意力：先沿通道维进行平均池化和最大池化，再使用卷积生成空间权重图。

  通道注意力回答“哪些通道更重要”，空间注意力回答“哪些位置更重要”。两者可以串联或并联使用，但增加注意力模块也会带来额外参数和计算量，需要通过实验验证是否真正提升性能。

### 5. ShuffleNet 中的通道 shuffle 如何用代码实现？

  假设输入张量形状为 (N,C,H,W)，分成 (G) 组。先把通道维拆成 (G,C/G)，再交换组维和组内通道维，最后恢复为原来的通道数：

```python
def channel_shuffle(x, groups):
    batch_size, channels, height, width = x.size()
    channels_per_group = channels // groups

    x = x.view(batch_size, groups, channels_per_group,
               height, width)
    x = torch.transpose(x, 1, 2).contiguous()
    x = x.view(batch_size, channels, height, width)
    return x
```

  通道重排后，来自不同分组的特征会重新混合，使下一层分组卷积能够接收不同组的信息，从而在保持较低计算量的同时增强特征交流。
